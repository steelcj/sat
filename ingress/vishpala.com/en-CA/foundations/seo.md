Search engines reward pages they can read and understand. The same choices that make this site accessible and portable also make it legible to a search crawler — so discoverability is a by-product of building well, not a separate plugin.

## Real structure, not decoration

Pages use semantic HTML: a single main heading, ordered sub-headings, and genuine landmarks. A crawler reads that structure the same way a screen reader does, and it can tell what a page is about because the markup actually says so.

## The signposts search engines expect

A sitemap lists the site's pages, canonical links tell search engines which URL is authoritative, and clean, readable URLs describe where a page sits. These are generated as part of the build, so they stay correct as the site changes rather than drifting out of date.

## Multilingual done right for search

Each page declares its language, and its translations are linked with `hreflang` annotations, so a search engine can offer the right language version to the right visitor instead of treating the translations as duplicates competing with one another.
