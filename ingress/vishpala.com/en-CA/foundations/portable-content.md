Content you cannot take with you is content you only rent. Everything on this site is stored in a form you can open, read, and move without permission from anyone.

## Plain text you can read

Each page is a Markdown file — plain text with light, human-readable formatting. You can open it in any editor, search it, diff it, and put it under version control. There is no proprietary database to export from and no page-builder format that only one product understands.

## Open, standard metadata

The information *about* each page — its title, language, identity, and dates — is written in Dublin Core, a metadata standard that libraries and archives have used for decades. Any tool that understands Dublin Core understands these files, which means the meaning travels with the content, not just the words.

## It outlives its tools

Because the format is open and standard, the content keeps working even if the tools that created it go away. If the CMS is retired, if this site framework is replaced, if the upstream archive changes — the files are still just Markdown and standard metadata, ready for the next tool. The content does not depend on any single program staying alive.
